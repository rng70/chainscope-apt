chainscope APT repository

Call-graph chain explorer: load *_cg.json call graphs, pick a source and a sink, and see every call chain between them — within one graph or stitched across several.

Install

curl -fsSL https://rng70.github.io/chainscope-apt/install.sh | sudo sh
sudo apt install chainscope-gui   # desktop application
sudo apt install chainscope       # or: static CLI only

Packages

PackageContents
chainscopemetapackage — pulls in the CLI build
chainscope-clifully static build, no dependencies (servers, containers, CI)
chainscope-guibuild with the graphical explorer + desktop entry

chainscope-cli and chainscope-gui both provide /usr/bin/chainscope and are mutually exclusive — installing one replaces the other.

Architectures: amd64, arm64, armhf.
